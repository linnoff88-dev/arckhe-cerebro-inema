What it is

Three brains, because memory isn’t just one thing

There are 3 types of memory with opposite needs — corresponding to the 3 types in cognitive science. Mixing them bloats the brain. Each gets its own folder, rule, and skill; the [[wikilinks]] cross-link with one another.

📁 1 · Project

What happened: decisions, state, next actions. Memory episodic — changes every day and is then archived. Append-only and dated. The LLM here records faithfully.

🧭 2 · Self

Who you are: values, beliefs, thoughts, open questions. Memory of identity — changes slowly, it’s your. The LLM here questions you, doesn't agree.

📚 3 · Knowledge

Facts about the world, what you learned. Memory of reference — only accumulates; it’s searchable. The LLM here distills raw material into a wiki connected.

How it works

The brain is the files. CLAUDE.md is the map.

It’s not software with a hidden database—the memory is your file system. Claude Code reads the CLAUDE.md at the start of every session; it routes you to the right folder without searching through everything. Since it’s just text, it survives the hype: the model changes, the brain stays.

raw material→ 0-inbox/→ /triage→ right brain→ /nota distills → wiki→ becomes context for the next session

🗺️ Router

O CLAUDE.md stores the vault map + the rules (voice, design, where to look). It’s the most important piece.

♻️ Raw→wiki loop

The LLM reads the raw material and assembles the wiki with [[wikilinks]]. You drop things in and review — you don't curate by hand. The wiki grows and improves every future answer.

🔗 4 layers

Organization (this project) + Format (kepano) + Retrieval (graphify) + Visualization (brain-map). Only the 1st is required.

User guide · step by step

From zero to your running brain

Real commands. The setup.sh creates the vault for the 3 brains; you do everything else by talking with Claude.

1

Clone and install

Creates the vault with the structure for the 3 brains (by default in ~/cerebro).

git clone https://github.com/inematds/cerebro-inema.git
cd cerebro-inema
./setup.sh              # or: ./setup.sh ~/meu-cerebro
2

Customize (interview)

Open Claude Code in the vault folder and run setup. It interviews you in plain text and fills in the CLAUDE.md and the Self brain.

cd ~/cerebro
# in Claude Code:
/setup-cerebro
3

Capture and route

Throw anything into 0-inbox/ without thinking about where. Then route it to the right brain.

# drop notes, links, PDFs in 0-inbox/ — then:
/triagem            # classifies and moves to the right brain
4

Distill knowledge

Turn a raw source into a connected atomic note (brain 3), with valid wikilinks.

/nota               # source → wiki note in 3-conhecimento/notes/
5

Think together (Self brain)

When you want tension instead of validation: the LLM challenges you and raises contradictions with your values.

/socratica          # the LLM questions, it doesn't agree
6

End the session

Saves decisions, lessons learned, and next actions to the right brain + updates the memory.

/daily   # starts the day with context
/tldr    # saves the session summary in the right place

The 4 layers

Only organization is required. The other three are optional foundations—install them as the brain grows.
