# 0-inbox — Captura

> **Joga tudo aqui primeiro.** Nota solta, link, PDF, ideia no meio da
> conversa, arquivo que chegou. Não pense onde vai — captura crua.
>
> Depois rode `/triagem`: o Claude lê cada item e roteia pro cérebro certo
> (Projeto, Self ou Conhecimento).
>
> Regra de ouro: **nada nasce classificado.** A inbox existe pra você não
> travar decidindo onde guardar — guarda aqui, organiza depois.
